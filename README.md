One funny line for the door of a haunted server room: the previous admin died in 2011, but his login session never timed out — so the sign warns you he is still logged in. A tiny deterministic program writes the line to `entry.txt` for make.fun's "Funniest Sign on a Haunted Server Room Door" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
